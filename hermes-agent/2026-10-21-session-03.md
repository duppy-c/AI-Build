### 2026-10-21 13:38-13:49 | Research: Docker vs Podman

- Docker supports Debian 13 Trixie, arm64; 64-bit Raspberry Pi OS uses Docker's Debian steps.
- Hermes Docker sandbox hardening: all capabilities dropped (DAC_OVERRIDE, CHOWN, FOWNER re-added), no-new-privileges, pids-limit 256, size-limited tmpfs.
- Podman supported via HERMES_DOCKER_BINARY=podman.
- Docker group 'grants root-level privileges to the user'; exposed ports 'bypass your firewall rules'.
- Rootless Podman limits: no ports <1024, no ping out of the box, can't reach host's main IP from container, no device nodes, no checkpoint/restore.
- Subagents: up to 10 concurrent by default (delegation.max_concurrent_children). One shared persistent sandbox container across subagents.
- User requirement recorded: agent must be able to deploy at least five agents. Neither option blocks this.

*Verification:* Verified: Docker docs (Debian, Raspberry Pi OS, post-install, firewalls); Hermes docs (configuration, docker, delegation); Podman rootless manual.
