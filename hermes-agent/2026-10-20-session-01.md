## Timestamped log

### 2026-10-20 07:48 | Feasibility: Hermes Agent on a Raspberry Pi

- Question: can Hermes Agent be put on an SD card and run on a Raspberry Pi?
- Finding: the SD card holds the Pi's operating system. Hermes is installed on the Pi itself after it boots.
- Finding (raspberry.tips): a Pi 4 with 4 GB is sufficient when the AI model runs in the cloud; a Pi 5 with 8 GB is recommended for fully local models.
- Finding: official Hermes is not built for Pi 2 / 1 GB boards; an unofficial community IoT fork exists (not used).

### 2026-10-21 02:48 | Session paused (OPEN ITEM: overscan)

- Option A (try first): on the Sharp remote, set View Mode / Picture Size to Dot by Dot, Full Pixel, or Just Scan.
- Option B: back up cmdline.txt, then append video margins to the END of its single line (no new line), save, reboot. Raise margins if still clipped; lower if black borders appear.
- Recovery for Option B: if the Pi fails to boot, put the card in the Windows PC, open the boot drive, edit cmdline.txt in Notepad, and remove the added text.
- Margin syntax verified against Raspberry Pi kernel command-line documentation.

Commands:

```

```
